# rachitrastogi.com

Personal portfolio — AI Engineering Leader & Platform Architect.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Configured for Cloudflare Pages (`wrangler.toml`). Build output: `dist/`.

## Content

Edit data files in `src/data/` — profile, career, photos, projects, skills.

Resume PDF: `public/Rachit_Rastogi_Resume.pdf`.
